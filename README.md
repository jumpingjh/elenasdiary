# Elena's Diary

*A story-driven pixel-art adventure about choices, relationships, self-discovery, and finding your own path.*

## About the Game

**Elena's Diary** is a 2D narrative adventure following Elena Leto, a 13-year-old girl navigating school, relationships, unexpected changes, sensory discomfort, and the small decisions that shape the way she understands herself and the world around her.

The game combines exploration, dialogue, environmental puzzles, a lightweight inventory, and behavioral choices.

Rather than presenting choices as explicitly right or wrong, the game allows different approaches to influence Elena's thoughts, relationships, reactions, and diary.

## Key Features

- Story-driven 2D adventure
- Pixel-art presentation
- Exploration and contextual interactions
- Environmental and narrative puzzles
- Lightweight inventory system
- Choices with consequences
- Hidden character-development variables
- Sensory and perception mechanics
- Elena's diary as a recurring narrative element
- 1990s setting
